PDF-försättsbladets layout

Styr vad som visas på den genererade PDF:ens försättsblad, och i vilken ordning. Tomma fält hoppas alltid över automatiskt - att ett fält är kopplat här betyder inte att det syns på varje PDF, bara på de där kolumnen faktiskt har ett värde. Varje rullista visar de kolumner verktyget faktiskt känner till med namn (t.ex. "Datum: Datum för händelsen") - se kolumnmappning nedan för att ändra vad någon av dem pekar på, inklusive radidentitet, upptäckt av bilagor och kategorimappen, som inte alls erbjuds som val här. Om ett val visar "hittades inte i senaste hämtningen" kanske kalkylbladets riktiga kolumnnamn inte matchar det som är konfigurerat - det rättas också nedan.

Kalkylbladets kolumnmappning

Kopplar varje sak verktyget behöver från kalkylbladet till den riktiga kolumnrubriken i ditt Google Form/kalkylblad - detta är rättningen för en rullista någon annanstans som visar en kolumn som visar sig sakna data, eller en "hittades inte"-varning på PDF-layouten ovan. Kolumnen "Exempelvärde" visar vad kolumnen faktiskt innehåller på första hämtade raden, så att du kan bekräfta en mappning innan du sparar istället för att gissa. Att välja "(Standard)" lämnar inställningen helt okopplad här, och överlåter till .env eller det inbyggda standardvärdet istället - rätt val för en kolumn som helt enkelt inte finns i ett givet kalkylblad (t.ex. körda mil, för ett utskott som aldrig ger reseersättning).

Ändringar börjar gälla direkt, redan vid nästa åtgärd - ingen omstart av `kvittomall webui` eller något CLI-kommando behövs, precis som för PDF-layouten ovan.
